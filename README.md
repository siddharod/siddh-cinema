## Run Locally

Interested in exploring the code or running the portfolio on your machine?

**Prerequisites:** Node.js and npm.

```bash
git clone https://github.com/siddharod/Portfolio.git
cd Portfolio
npm install
npm run dev
```

To generate a production build:

```bash
npm run build
```

The generated site is available in the `dist/` directory.

## Deployment

The portfolio is configured for static hosting through GitHub Pages, with a Vite production build and GitHub Actions deployment workflow.
