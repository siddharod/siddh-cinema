## Getting Started

To run the portfolio locally, ensure that Node.js and npm are installed.

```bash
git clone https://github.com/siddharod/Portfolio.git
cd Portfolio
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

The generated production files are available in the `dist/` directory.
