## About the Project

This repository contains my personal developer portfolio, designed around a cinematic streaming-platform experience inspired by Amazon Prime Video.

Instead of presenting a conventional résumé page, the portfolio introduces visitors to different perspectives of my journey, whether they are recruiters, developers, or people interested in my work.

The experience combines a dark visual identity, interactive profile selection, featured projects, professional information, and résumé access in one cohesive interface.

## Highlights

- **Cinematic UI:** A dark interface with electric-blue accents and carefully designed visual hierarchy.
- **Interactive Experience:** A profile-selection experience that guides visitors toward relevant portfolio content.
- **Project Showcase:** Dedicated presentations for selected software projects and their technical details.
- **Recruiter-Friendly Résumé:** Access to my résumé and professional background.
- **Technical Journey:** A consolidated view of my skills, education, internships, achievements, and certifications.
- **Responsive Design:** An interface designed to adapt to desktop, tablet, and mobile screens.
- **Performance and Accessibility:** Focus on efficient loading, keyboard navigation, and usable interactions.

## Getting Started

Want to run the portfolio locally?

### Prerequisites

- Node.js and npm
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/siddharod/Portfolio.git

# Enter the project directory
cd Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal to explore the portfolio.

### Production Build

```bash
npm run build
```

The production-ready files are generated in the `dist/` directory.

## Deployment
